# JARVIS's skills

This folder holds abilities JARVIS wrote for itself with its `create_skill` tool
(after you approved the code). Every `.py` file here is loaded automatically
when JARVIS starts.

- To remove a skill: ask JARVIS ("remove the csv_to_json skill") or delete the file.
- Files starting with `_` are ignored.
- You can write skills yourself too. `word_count.py` is a small example.
